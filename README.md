# 泛音 Overtone · Android 0.11.4

本地音乐播放器，Android 8.0 起。无需登录，应用未申请联网或麦克风权限。

1. 点曲库右上角的「+」，选「自动找歌」并授权音乐和音频。播放器使用 Android 本机媒体索引。标签或歌词等音乐证据足够的音频直接收录，录音、铃声等明显非音乐跳过，剩余文件可在「待确认音频」试听、收录或跳过。可在「导入音乐 → 筛选结果」查看已跳过的文件并恢复。选择文件夹会按所选来源导入。歌仍留在原位置。
2. 曲库从左到右是文件夹、专辑、歌曲、收藏四个图标，底部短线标记当前分类。点右上角放大镜可搜索文件名、歌名、歌手和专辑。长按歌名可插播、加入队列或收藏。
3. 点迷你播放条进入竖屏播放页。左右滑动中央区域可切换封面、歌词和可视化。封面下方的小圆点会显示当前页。进度、时间和播放键固定在底部，平板竖屏的工具、歌词和进度条共用左右对齐线，播放键在进度条下方居中。封面按原比例显示，同图模糊色调延展到剩余空间。封面配色贯穿曲库、播放页和弹层，曲库「更多」里可关闭。无封面或黑白封面使用中性色。
4. 可视化铺满播放页背景，中心与封面中心对齐，沿用当前专辑封面的主色和辅色。迷你播放条的声波图标直达可视化。「随音乐」根据响度、频段分布和低频突发特征选择流光、粒子星环或棱镜，也可手动切换上述场景、频谱瀑布、柱状频谱、波形和环形频谱。曲库「更多」里的「试听可视化」可用内置音轨体验。
   - 可视化页的马达图标和曲库「更多」都可开启「音乐触感」。默认关闭，在前台播放页播放时根据低频突起产生轻短触感，优先使用硬件支持的系统轻点，其余机型使用短脉冲。暂停、退出播放页或切到后台时停止。
5. 播放页右上角可打开均衡器。「简单调整」有摇滚、重低音、流行、人声、爵士、古典等预设，也能手调低、中、高三段。「专业调整」有十段参数均衡、前级增益及每段启用开关。点数值可精确输入。频响图反映当前模式、前级及自动余量。预设可保存到本机。
6. 播放页的「音频信息」显示编解码器、解码后的 PCM 和应用实际交给 Android 的 AudioTrack 格式。「原音」可旁通 EQ 并保留其设置。连接 DAC 后可在同一页打开「USB 逐位」，激活后显示 DAC 名称和实际 USB 输出。
7. 歌词优先匹配同目录下同名的 `.lrc`，也会读取 MP3 的 ID3 内嵌歌词，带时间戳可同步滚动及点按跳转。读取同名文件受 Android 存储权限影响，可从歌词页点文件夹图标授权歌曲所在文件夹，或通过曲库的「选择文件夹」授权后重新扫描。

安卓 11 及以上可能不允许直接选内部存储根目录或 Download 根目录。可选择 Music，或 Download 下的普通子目录。SD 卡也应选择子目录。

模拟器上实际测试了 MP3、24-bit FLAC、AAC/M4A、ALAC/M4A、24-bit PCM WAV、Ogg/Vorbis、Ogg/Opus、ADTS AAC、AC-3、E-AC-3、MKA/FLAC，以及后台媒体按键切歌、曲库与队列恢复、同名 LRC。个别容器里的具体编码仍决定文件能否播放。当前不支持 APE、DSD 或整轨 CUE 分轨。蓝牙耳机、实际设备音频路由及长时间稳定性尚未做真机验证。

## 本地编译

JDK 17 或 21、Android SDK Platform 36，运行 `./gradlew :app:assembleDebug`。APK 在 `app/build/outputs/apk/debug/`。项目使用 Compose 绘制界面，Media3 提供播放与系统媒体会话，频谱从解码后的 PCM 计算。第三方授权及对应源码位置见 THIRD_PARTY.md。

均衡器处理发生在应用内的 PCM 播放链，采用 [W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/) 的双二阶滤波器公式。数值验证入口为 `tools/EqCheck.kt`。

FLAC、ALAC 优先使用 FFmpeg。播放链按解码输出处理 PCM，16 位 PCM 旁通时直接送入 Media3，高位深 PCM 可通过 32 位浮点路径送至 AudioTrack。24 位整数的样本值可用 32 位浮点精确表示，32 位整数的全精度则超出 32 位浮点的有效位数。应用内保留采样率并不代表系统混音、蓝牙传输或 USB DAC 输出逐位一致。PCM 字节和低幅样本验证入口为 `tools/PcmCheck.kt`。

USB 逐位使用 [Android 14 的 USB 混音器接口](https://source.android.com/docs/core/audio/preferred-mixer-attr)。需 Android 系统和 DAC 路由提供可用的 BIT_PERFECT 配置。匹配音源的采样率与声道，优先同位深，也可无损补零到更宽的整数 PCM 容器。只有系统读回请求的配置且 AudioTrack 确认路由到该 DAC，才显示「实际 USB 输出」。无匹配配置时使用系统播放。USB 逐位默认关闭，开启时旁通 EQ，并在 DAC 上调音量。当前逐位路径面向可验证位深的 PCM、FLAC、ALAC，浮点解码无法完整表示 32 位整数时回退到系统播放。硬件验收可用 44.1 kHz 和 96 kHz 音轨切换，对照音频信息和 DAC 的采样率指示。策略与无损 PCM 打包测试位于 `tools/UsbPcmCheck.kt`。
